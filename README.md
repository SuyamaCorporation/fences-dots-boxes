# 24 - フェンスでドット結びゲーム

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: fences-dots-boxes

## 概要
格子点を線で繋いで正方形を最多獲得するドット&ボックスゲーム。CPU対戦あり。四辺すべて囲んだプレイヤーがそのマスを獲得します。

## 機能
- Canvas描画の5×5格子(4×4=16マス)
- 線の上をクリックして引く（ホバーでプレビュー表示）
- マスを完成させると同じプレイヤーが連続手番
- CPUの戦略AI: ①完成可能なマスを優先②相手に3辺渡さない③ランダム
- プレイヤー(青)とCPU(赤)のスコア表示
- 全マス完成で勝敗判定（勝ち/負け/引き分け）
- 「もう一度」ボタンでリセット
